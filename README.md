# Health-Aware Route Planning for Asthma Patients

A data-driven pathfinding and traffic simulation system designed to optimize safe navigation routes for asthma patients by integrating real-time environmental conditions, air quality data, and heuristic routing algorithms.

## Key Features
- **Traffic & Urban Simulation:** Built using SUMO (Simulation of Urban MObility) to model real-world road networks and traffic flow.
- **Health-Aware Pathfinding:** Optimizes routes to minimize exposure to pollution hotspots and environmental triggers.
- **Automated Execution & Data Logging:** Python scripts (`run_map.py`) to configure, execute, and export vehicle/person telemetry data (`SumoData`).

## Research & Publications
This work contributed to two peer-reviewed international conference papers:
1. **IEEE IMSA 2025:** *"Health-Aware Path Planning Using Environmental Data & Sequential Prediction Models"* (Giza, Egypt).
2. **ICACIN 2024:** *"Health-Aware Heuristic Modelling for Asthma-Friendly Route Optimization"* (Birmingham City University, UK).
